# Fleet Management API

A small FastAPI application for managing vehicles, drivers, trips, and maintenance records. It uses SQLite for persistence via SQLModel and exposes REST endpoints for common fleet workflows.

## Features
- CRUD operations for vehicles and drivers
- Trip creation and completion with automatic vehicle status updates and mileage tracking
- Maintenance ticketing with status tracking per vehicle
- Relationship filters for listing trips or maintenance entries for a given vehicle or driver

## Getting Started

### Requirements
- Python 3.11+

### Installation
1. Create a virtual environment and install dependencies:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. (Optional) Set a custom database location via `DATABASE_URL` (defaults to `sqlite:///fleet.db`).

### Running the API
Start the development server with Uvicorn:
```bash
uvicorn app.main:app --reload
```

Visit the interactive docs at http://127.0.0.1:8000/docs.

## API Overview
- `POST /vehicles` / `GET /vehicles` / `GET /vehicles/{id}` / `PUT /vehicles/{id}` / `DELETE /vehicles/{id}`
- `POST /vehicles/{id}/status` — update a vehicle's status
- `GET /vehicles/{id}/trips` — list trips for a vehicle
- `GET /vehicles/{id}/maintenance` — list maintenance records for a vehicle
- `POST /drivers` / `GET /drivers` / `GET /drivers/{id}` / `PUT /drivers/{id}` / `DELETE /drivers/{id}`
- `GET /drivers/{id}/trips` — list trips assigned to a driver
- `POST /trips` / `GET /trips` / `GET /trips/{id}` / `PUT /trips/{id}` / `DELETE /trips/{id}`
- `POST /trips/{id}/complete` — mark a trip complete and return the vehicle to `available`
- `POST /maintenance` / `GET /maintenance` / `PUT /maintenance/{id}` / `DELETE /maintenance/{id}`

Payloads follow the schemas in `app/models.py`; example create payloads are available in the autogenerated docs.
